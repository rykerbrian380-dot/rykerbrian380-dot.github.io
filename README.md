# Brian's Lab

Personal website practice project published with GitHub Pages.

Live site: https://rykerbrian380-dot.github.io/

## Features

- Neon-style homepage
- Launch button with click counter
- Reset button for restoring the default message and count
- Theme button for switching between dark and light styles
- Keyboard shortcut: press `L` to trigger Launch

## Project Structure

- `index.html`: The website page, including HTML, CSS, and JavaScript
- `README.md`: Project notes and usage guide

## Workflow

1. Create an issue for a new idea or feature.
2. Create a branch for the change.
3. Make and test the update locally.
4. Commit with a clear summary.
5. Push the branch to GitHub.
6. Open a pull request and review the diff.
7. Merge into `main`.
8. Check the GitHub Pages site after deployment.
